# Produtos Notáveis: Exercícios

**Teoria:** [[Produtos Notáveis]] · **Gabarito:** [[Produtos Notáveis - Gabarito]]

> [!info] Como fazer
> Escreva a resposta **direto**, sem o chuveirinho. Se errar, confira refazendo a multiplicação completa. Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** $(x + 3)^2$
- [ ] **2.** $(x - 5)^2$
- [ ] **3.** $(a + 4)(a - 4)$
- [ ] **4.** $(2x + 1)^2$
- [ ] **5.** $(3a - 2b)^2$
- [ ] **6.** $(x^2 + 1)(x^2 - 1)$
- [ ] **7.** Calcule de cabeça: $51^2$ e $99 \cdot 101$.
- [ ] **8.** Complete: $x^2 + 8x + \_\_ = (x + \_\_)^2$

## 🟡 Médio
- [ ] **1.** 🔀 $\left(\frac{x}{2} + \frac{1}{3}\right)^2$
- [ ] **2.** 🔀 $(0{,}5a - 2)^2$
- [ ] **3.** 🔀 (a) $(\sqrt{3} + \sqrt{2})(\sqrt{3} - \sqrt{2})$ (b) $(\sqrt{5} + 1)^2$
- [ ] **4.** $(x + 2)^3$
- [ ] **5.** Simplifique: $(x + 1)^2 - (x - 1)^2$
- [ ] **6.** Calcule $2026^2 - 2025^2$ sem calcular os quadrados.
- [ ] **7.** Se $a + b = 7$ e $ab = 10$, quanto vale $a^2 + b^2$?
- [ ] **8.** Desenvolva $(x + y + 1)^2$. (Dica: trate $(x + y)$ como um bloco só.)

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** Calcule $\dfrac{1000^2}{252^2 - 248^2}$ sem calculadora.
- [ ] **2.** Se $x + \frac{1}{x} = 3$, calcule $x^2 + \frac{1}{x^2}$. Desafio extra: e $x^3 + \frac{1}{x^3}$?
- [ ] **3.** Mostre que o produto de quatro inteiros consecutivos, mais 1, é sempre um quadrado perfeito. (Dica: multiplique o 1º pelo 4º e o 2º pelo 3º.)
- [ ] **4.** Calcule $\sqrt{2026 \cdot 2024 + 1}$.

## 💻 Extra em C# (opcional)
- [ ] **1.** Sorteie 1.000 pares `(a, b)` com `Random` e confira que $(a + b)^2$ e $a^2 + 2ab + b^2$ dão o mesmo resultado (com tolerância, por causa do `double`). Depois confira que $(a + b)^2$ e $a^2 + b^2$ **não** dão.
- [ ] **2.** Escreva `double DistanciaAoQuadrado(double[] a, double[] b)` de dois jeitos: somando $(a_i - b_i)^2$ e usando $\lVert a \rVert^2 - 2\,a \cdot b + \lVert b \rVert^2$. Compare os resultados.
