## 🟡 Médio
**1.** $6x^2 + 8x - 3x - 4 = 6x^2 + 5x - 4$
**2.** $x^3 + 2x^2 + 4x - 2x^2 - 4x - 8 = x^3 - 8$
**3.** $\frac{1}{2}x \cdot 2x = x^2$; $\;\frac{1}{2}x \cdot 4 = 2x$; $\;-0{,}5 \cdot 2x = -x$; $\;-0{,}5 \cdot 4 = -2$. Total: $x^2 + x - 2$.
**4.** $P(-1) = 2 + 3 + 1 = 6$; $\;P\left(\frac{1}{2}\right) = \frac{2}{4} - \frac{3}{2} + 1 = 0$; $\;P(\sqrt{3}) = 6 - 3\sqrt{3} + 1 = 7 - 3\sqrt{3}$.
**5.** $2x - 6 - 6 + 3x + x^2 - x = x^2 + 4x - 12$
**6.** Área: $2x^2 + x - 3$. Perímetro: $6x + 4$.
**7.** Quociente $x + 3$ e resto 0.
**8.** $(0{,}2 \cdot 5)x^3 = x^3$. E $\frac{x^3 - 3x}{x} = x^2 - 3$. Então $x^3 - (x^2 - 3) = x^3 - x^2 + 3$.

## 🧮 Treino: operações entre polinômios

### Soma e subtração
**S1.** $3x^3 + 3x^2 - 3x + 3$
**S2.** $5x^2 - 3x + 2 - 2x^2 - x + 6 = 3x^2 - 4x + 8$
**S3.** $3a^2b - 5ab + 4b^2$
**S4.** $x^2$: $0{,}5 + 1{,}5 = 2$; $\;x$: $-\frac{1}{2} + \frac{1}{3} = -\frac{1}{6}$; $\;$constante: $1 - 2 = -1$. Resultado: $2x^2 - \frac{1}{6}x - 1$.
**S5.** $(x^2 + 2x^2 + x^2) + (-3x + x) + (2 - 5 - 4) = 4x^2 - 2x - 7$ (o $-R$ troca os sinais: $+x^2 - 4$)

### Multiplicação
**M1.** $x^2 - 3x - 28$
**M2.** $6x^2 + 15x - 4x - 10 = 6x^2 + 11x - 10$
**M3.** $x^3 - 2x^2 + x^2 - 2x - x + 2 = x^3 - x^2 - 3x + 2$
**M4.** Na tabela, os 9 produtos são: $2x^4, 4x^3, -8x^2$ (do $2x^2$); $\;-3x^3, -6x^2, 12x$ (do $-3x$); $\;x^2, 2x, -4$ (do $+1$). Juntando: $2x^4 + x^3 - 13x^2 + 14x - 4$.
**M5.** $(x^2 - 1)(x^2 + 1) = x^4 - 1$ (duas diferenças de quadrados seguidas)
**M6.** $2x^2 - 1{,}5x + \frac{8}{3}x - 2$. Como $-\frac{3}{2} + \frac{8}{3} = \frac{-9 + 16}{6} = \frac{7}{6}$: $\;2x^2 + \frac{7}{6}x - 2$.
**M7.** $a^3 - 2a^2b + 4ab^2 + 2a^2b - 4ab^2 + 8b^3 = a^3 + 8b^3$ (quase tudo se cancela: é a "soma de cubos")
**M8.** $(x^2 - 3x + 2)(2x^2 + x - 5) = 2x^4 - 5x^3 - 4x^2 + 17x - 10$

### Divisão
**D1.** $2x^2 - 3x + 1$, resto 0
**D2.** $x + 5$, resto 0
**D3.** $x - 2$, resto 0
**D4.** $2x - 1$, resto 0. (Passos: $2x^2 \div x = 2x$; $\;2x(x + 2) = 2x^2 + 4x$; sobra $-x - 2$; $\;-x \div x = -1$; $\;-1 \cdot (x + 2) = -x - 2$; sobra 0.)
**D5.** $x^2 + 2x + 4$, resto 0. (Com $x^3 + 0x^2 + 0x - 8$: $x^2$ → sobra $2x^2 + 0x - 8$ → $2x$ → sobra $4x - 8$ → $4$ → sobra 0.)
**D6.** $x + 2$, **resto 3**. Verificação: $(x + 1)(x + 2) + 3 = x^2 + 3x + 2 + 3 = x^2 + 3x + 5$ ✔️
**D7.** Quociente $2x - 1$, **resto $-2x + 2$** (o resto tem grau 1, menor que o grau 2 do divisor, então a divisão termina aí).
Passos: $2x^3 \div x^2 = 2x$; $\;2x(x^2 + x - 1) = 2x^3 + 2x^2 - 2x$; sobra $-x^2 - 3x + 3$. Depois, $-x^2 \div x^2 = -1$; $\;-1 \cdot (x^2 + x - 1) = -x^2 - x + 1$; sobra $-2x + 2$.
**D8.** $x^2 - 1$, resto 0
**D9.** Teorema do resto no D6: o divisor é $x + 1 = x - (-1)$, então o resto é $P(-1) = 1 - 3 + 5 = 3$ ✔️. Briot-Ruffini no D3, com $a = 3$ e coeficientes $1, -5, 6$: desce o 1; $\;1 \cdot 3 - 5 = -2$; $\;-2 \cdot 3 + 6 = 0$. Quociente $x - 2$, resto 0 ✔️.

### Misturando operações
**X1.** $(x^2 + 4x + 4) - (x^2 + 2x - 3) = 2x + 7$
**X2.** $(x^3 - 1) \div (x - 1) = x^2 + x + 1$. Somando $(x - 1)^2 = x^2 - 2x + 1$: $\;2x^2 - x + 2$.
**X3.** $2x^2 - 6x - (2x^2 - 3x - 2) = -3x + 2$

## 🔴 Difícil
**1.** $(x + a)(x + b) = x^2 + (a + b)x + ab$. Precisamos de $a + b = 7$ e $ab = 12$, ou seja, **$a = 3$ e $b = 4$** (ou o contrário).
💡 *Essa ideia de soma e produto é a base da [[Fatoração]] de trinômios e de [[Equações do 2º Grau]].*

**2.** **11.**
Um termo em $x^2$ aparece quando escolhemos o "$x$" de **dois** parênteses e o "1" do outro: $1x \cdot 2x \cdot 1 + 1x \cdot 1 \cdot 3x + 1 \cdot 2x \cdot 3x = 2x^2 + 3x^2 + 6x^2 = 11x^2$.
(Conferindo pelo produto completo: $(1 + x)(1 + 2x) = 1 + 3x + 2x^2$, e vezes $(1 + 3x)$ dá $1 + 6x + 11x^2 + 6x^3$. ✔️)

**3.** **1.**
Para qualquer polinômio, $P(1)$ é a soma dos coeficientes (porque $1^n = 1$, e cada termo vira só o seu coeficiente). Então a soma é $(3 \cdot 1 - 2)^{2026} = 1^{2026} = 1$.

**4.** **2.**
Com $x = 1$: $P(1) = (1 - 1) \cdot Q(1) + r = r$. E $P(1) = 1 - 2 + 3 = 2$. (Esse é o **teorema do resto**.)

## 💻 Extra em C#
**1.**
```csharp
double Avaliar(double[] coef, double x)
{
    double resultado = 0;
    for (int i = coef.Length - 1; i >= 0; i--) // do maior expoente para o menor
        resultado = resultado * x + coef[i];
    return resultado;
}
```
**2.**
```csharp
double[] Multiplicar(double[] p, double[] q)
{
    var r = new double[p.Length + q.Length - 1];
    for (int i = 0; i < p.Length; i++)
        for (int j = 0; j < q.Length; j++)
            r[i + j] += p[i] * q[j]; // xⁱ · xʲ = xⁱ⁺ʲ
    return r;
}
```
O `r[i + j]` é a propriedade "somar os expoentes" das potências.
