# Monômios e Polinômios: Exercícios

**Teoria:** [[Monômios e Polinômios]] · **Gabarito:** [[Monômios e Polinômios - Gabarito]]

> [!info] Como fazer
> Resolva no caderno. Nas multiplicações de polinômios, use o **método da tabela** até ficar automático. Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** Dê o coeficiente e o grau: (a) $-4x^3y^2$ (b) $7$ (c) $\frac{x}{2}$
- [ ] **2.** Reduza os termos semelhantes: (a) $3x + 5x - 2x$ (b) $4a^2 - a + 2a^2 + 3a$ (c) $2xy - 3yx$
- [ ] **3.** $(3x^2 - 2x + 1) + (x^2 + 5x - 4)$
- [ ] **4.** $(5a - 3b) - (2a - 4b)$
- [ ] **5.** (a) $(2x^3) \cdot (-3x^2)$ (b) $(-a^2b) \cdot (4ab^3)$
- [ ] **6.** $3x(2x - 5)$
- [ ] **7.** $(x + 2)(x + 3)$
- [ ] **8.** $(12x^4 - 8x^3 + 4x^2) \div (4x^2)$

## 🟡 Médio
- [ ] **1.** $(2x - 1)(3x + 4)$
- [ ] **2.** $(x - 2)(x^2 + 2x + 4)$
- [ ] **3.** 🔀 $\left(\frac{1}{2}x - 0{,}5\right)(2x + 4)$
- [ ] **4.** 🔀 Sendo $P(x) = 2x^2 - 3x + 1$, calcule $P(-1)$, $P\left(\frac{1}{2}\right)$ e $P(\sqrt{3})$.
- [ ] **5.** Simplifique: $2(x - 3) - 3(2 - x) + x(x - 1)$
- [ ] **6.** Um retângulo tem lados $2x + 3$ e $x - 1$. Escreva a área e o perímetro na forma reduzida.
- [ ] **7.** Divida $x^2 + 5x + 6$ por $x + 2$ pelo método da chave (seção 7 da teoria).
- [ ] **8.** 🔀 Simplifique: $(0{,}2x^2)(5x) - \dfrac{x^3 - 3x}{x}$

## 🧮 Treino: operações entre polinômios
*Um bloco só para ganhar mão nas contas. Use $P(x) = x^2 - 3x + 2$, $\;Q(x) = 2x^2 + x - 5$ e $\;R(x) = -x^2 + 4$ onde aparecerem.*

### Soma e subtração
- [ ] **S1.** $(2x^3 - x + 4) + (x^3 + 3x^2 - 2x - 1)$
- [ ] **S2.** $(5x^2 - 3x + 2) - (2x^2 + x - 6)$
- [ ] **S3.** $(4a^2b - 3ab + b^2) - (a^2b + 2ab - 3b^2)$
- [ ] **S4.** 🔀 $\left(\frac{1}{2}x^2 - 0{,}5x + 1\right) + \left(1{,}5x^2 + \frac{1}{3}x - 2\right)$
- [ ] **S5.** $P(x) + Q(x) - R(x)$

### Multiplicação
- [ ] **M1.** $(x + 4)(x - 7)$
- [ ] **M2.** $(3x - 2)(2x + 5)$
- [ ] **M3.** $(x^2 + x - 1)(x - 2)$
- [ ] **M4.** $(2x^2 - 3x + 1)(x^2 + 2x - 4)$ (use a tabela 3 × 3)
- [ ] **M5.** $(x - 1)(x + 1)(x^2 + 1)$
- [ ] **M6.** 🔀 $\left(0{,}5x + \frac{2}{3}\right)(4x - 3)$
- [ ] **M7.** $(a + 2b)(a^2 - 2ab + 4b^2)$
- [ ] **M8.** $P(x) \cdot Q(x)$

### Divisão (dê o quociente e o resto)
- [ ] **D1.** $(6x^3 - 9x^2 + 3x) \div (3x)$
- [ ] **D2.** $(x^2 + 7x + 10) \div (x + 2)$
- [ ] **D3.** $(x^2 - 5x + 6) \div (x - 3)$
- [ ] **D4.** $(2x^2 + 3x - 2) \div (x + 2)$
- [ ] **D5.** $(x^3 - 8) \div (x - 2)$ (complete os termos que faltam com zero)
- [ ] **D6.** $(x^2 + 3x + 5) \div (x + 1)$
- [ ] **D7.** $(2x^3 + x^2 - 5x + 3) \div (x^2 + x - 1)$
- [ ] **D8.** $(x^4 - 1) \div (x^2 + 1)$
- [ ] **D9.** Confira o D6 com o teorema do resto e refaça o D3 com Briot-Ruffini.

### Misturando operações
- [ ] **X1.** $(x + 2)^2 - (x - 1)(x + 3)$ (lembre: $(x + 2)^2 = (x + 2)(x + 2)$)
- [ ] **X2.** $(x^3 - 1) \div (x - 1) + (x - 1)^2$
- [ ] **X3.** $2x(x - 3) - (x - 2)(2x + 1)$

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** Encontre os números $a$ e $b$ para que $(x + a)(x + b) = x^2 + 7x + 12$ para todo $x$.
- [ ] **2.** Qual é o coeficiente de $x^2$ no produto $(1 + x)(1 + 2x)(1 + 3x)$? Tente responder sem fazer a multiplicação completa.
- [ ] **3.** Qual é a **soma dos coeficientes** do polinômio que se obtém ao desenvolver $(3x - 2)^{2026}$? (Dica: o que acontece quando $x = 1$?)
- [ ] **4.** Qual é o resto da divisão de $P(x) = x^{100} - 2x + 3$ por $x - 1$? (Dica: escreva $P(x) = (x - 1) \cdot Q(x) + r$ e escolha um bom valor de $x$.)

## 💻 Extra em C# (opcional)
- [ ] **1.** Represente um polinômio como `double[] coef` (o índice é o expoente) e escreva `double Avaliar(double[] coef, double x)` com o **método de Horner**.
- [ ] **2.** Escreva `double[] Multiplicar(double[] p, double[] q)`. Teste com $(x + 2)(x + 3)$, ou seja, `{2, 1}` e `{3, 1}`, que deve dar `{6, 5, 1}`.
