# Linguagem Algébrica: Exercícios

**Teoria:** [[Linguagem Algébrica]] · **Gabarito:** [[Linguagem Algébrica - Gabarito]]

> [!info] Como fazer
> Resolva no caderno. No valor numérico, **substitua sempre entre parênteses**. Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** Traduza para a álgebra, usando $x$ para "um número":
  (a) o dobro de um número (b) a metade de um número (c) o quadrado de um número, menos 3 (d) o quadrado da diferença entre um número e 3 (e) o triplo da soma de um número com 5 (f) a soma do triplo de um número com 5
- [ ] **2.** Escreva em português: (a) $2x + 1$ (b) $\frac{x + y}{2}$ (c) $x^2 + y^2$ (d) $(x + y)^2$
- [ ] **3.** Calcule o valor de $3x - 5$ para $x = 4$, para $x = -2$ e para $x = \frac{1}{3}$.
- [ ] **4.** Calcule o valor de $x^2 - 2x$ para $x = -3$.
- [ ] **5.** Dê o coeficiente e a parte literal de cada termo: (a) $-5x^2y$ (b) $x$ (c) $-\frac{ab}{3}$ (d) $7$
- [ ] **6.** Use $F = 1{,}8C + 32$ para converter $25\,°C$ e $-10\,°C$ em Fahrenheit.
- [ ] **7.** Um retângulo tem lados $x$ e $x + 3$. Escreva o perímetro dele na forma mais simples e calcule-o para $x = 2{,}5$.
- [ ] **8.** Represente com letras: (a) três números inteiros consecutivos (b) um número par (c) um número ímpar (d) dois números pares consecutivos.

## 🟡 Médio
- [ ] **1.** 🔀 Calcule $\dfrac{a^2 - b}{a + b}$ para $a = -\frac{1}{2}$ e $b = 0{,}25$.
- [ ] **2.** 🔀 Calcule $2x^2 - 3x + 1$ para $x = 0{,}5$ e para $x = \sqrt{2}$.
- [ ] **3.** Um táxi cobra R\$ 5,50 de bandeirada mais R\$ 2,80 por km. Escreva o preço $P$ de uma corrida de $k$ km e calcule o preço de uma corrida de 12 km.
- [ ] **4.** Uma loja dá 15% de desconto em tudo e, depois, mais R\$ 10 de desconto no caixa. Escreva o preço final de um produto que custava $p$. Quanto paga quem leva um produto de R\$ 200?
- [ ] **5.** Mostre, com álgebra, que a soma de três números inteiros consecutivos é sempre um múltiplo de 3.
- [ ] **6.** Ana tem $x$ anos. O irmão dela tem o dobro da idade de Ana menos 4. A mãe tem a soma das idades dos dois mais 20. Escreva a idade da mãe em função de $x$, da forma mais simples possível.
- [ ] **7.** Um modelo de regressão faz previsões com $\hat{y} = 0{,}8x + 1{,}5$. Calcule $\hat{y}$ para $x = 10$ e para $x = -2{,}5$. Se o valor real para $x = 10$ era 9, qual foi o erro (previsto − real)?

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** "Pense num número, some 5, multiplique por 2, subtraia 4, divida por 2 e, por fim, subtraia o número que pensou." Prove que o resultado é **sempre** 3.
- [ ] **2.** Prove que o produto de dois números ímpares é sempre ímpar. (Dica: escreva os ímpares como $2a + 1$ e $2b + 1$ e use a [[Operações Fundamentais|distributiva]].)
- [ ] **3.** Prove que um número de dois algarismos somado ao número com os algarismos invertidos (por exemplo, $47 + 74$) dá sempre um múltiplo de 11. (Dica: [[Sistema de Numeração Decimal|valor posicional]].)
- [ ] **4.** Com palitos de fósforo, formamos uma fila de quadrados lado a lado (cada quadrado novo aproveita um lado do anterior). Com 1 quadrado são 4 palitos; com 2, são 7. Quantos palitos são necessários para $n$ quadrados? E para 100?

## 💻 Extra em C# (opcional)
- [ ] **1.** Escreva `Func<double, double> f = x => ...` para $f(x) = 2x^2 - 3x + 1$ e calcule $f(-2)$, $f(0{,}5)$ e $f(\sqrt{2})$. Compare com o 🟡 2.
- [ ] **2.** Em C#, o que imprime `int x = 3; x = x + 1; Console.WriteLine(x);`? Explique, em uma frase, por que a "equação" $x = x + 1$ não tem solução em matemática.
