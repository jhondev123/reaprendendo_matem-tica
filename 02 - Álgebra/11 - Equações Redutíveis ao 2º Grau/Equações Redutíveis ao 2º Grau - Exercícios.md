# Equações Redutíveis ao 2º Grau: Exercícios

**Teoria:** [[Equações Redutíveis ao 2º Grau]] · **Gabarito:** [[Equações Redutíveis ao 2º Grau - Gabarito]]

> [!info] Como fazer
> Dê o **conjunto-solução** real. Em equações com raiz, **verifique cada candidato** na equação original. Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** $x^4 - 5x^2 + 4 = 0$
- [ ] **2.** $x^4 - 16 = 0$
- [ ] **3.** $x^3 - 4x = 0$
- [ ] **4.** $(x - 2)(x^2 - 9) = 0$
- [ ] **5.** $x + \dfrac{6}{x} = 5$
- [ ] **6.** $\sqrt{x} = 3$
- [ ] **7.** $\sqrt{x + 1} = 4$
- [ ] **8.** $x = -1$ é solução de $\sqrt{x + 2} = x$? Justifique.

## 🟡 Médio
- [ ] **1.** $x^4 - 10x^2 + 9 = 0$
- [ ] **2.** $x^4 + 3x^2 - 4 = 0$
- [ ] **3.** $(x - 1)^2 - 5(x - 1) + 6 = 0$
- [ ] **4.** $\sqrt{x + 2} = x$
- [ ] **5.** $\sqrt{x + 5} = x - 1$
- [ ] **6.** $\dfrac{1}{x - 1} + \dfrac{1}{x + 1} = \dfrac{4}{3}$
- [ ] **7.** 🔀 $x^4 - 0{,}25x^2 = 0$
- [ ] **8.** 🔀 $\sqrt{2x + 1} = x - 1$
- [ ] **9.** 🔀 $(x^2 - 2)^2 = 0{,}\overline{1} \cdot 9$

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** $\sqrt{x + 7} + \sqrt{x} = 7$
- [ ] **2.** $(x^2 + x)^2 - 8(x^2 + x) + 12 = 0$
- [ ] **3.** $x + \dfrac{1}{x} = \dfrac{5}{2}$
- [ ] **4.** $x^{2/3} - 5x^{1/3} + 6 = 0$

## 💻 Extra em C# (opcional)
- [ ] **1.** Reaproveite o seu `Bhaskara` de [[Equações do 2º Grau]] e escreva `double[] Biquadrada(double a, double b, double c)`, que devolve todas as raízes reais de $ax^4 + bx^2 + c = 0$.
- [ ] **2.** Para $\sqrt{x + 5} = x - 1$, calcule os candidatos com Bhaskara e **filtre** só os que satisfazem a equação original, usando uma tolerância.
