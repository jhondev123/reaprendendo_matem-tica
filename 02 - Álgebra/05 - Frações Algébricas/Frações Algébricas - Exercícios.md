# Frações Algébricas: Exercícios

**Teoria:** [[Frações Algébricas]] · **Gabarito:** [[Frações Algébricas - Gabarito]]

> [!info] Como fazer
> **Fatore antes de qualquer coisa.** Na dúvida sobre uma simplificação, teste com um número (por exemplo, $x = 2$). Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** Dê a condição de existência: (a) $\frac{3}{x - 2}$ (b) $\frac{x + 1}{x^2 - 9}$ (c) $\frac{5}{x(x + 4)}$
- [ ] **2.** Simplifique: $\dfrac{6x^2y}{9xy^3}$
- [ ] **3.** Simplifique: $\dfrac{3x + 6}{x + 2}$
- [ ] **4.** Simplifique: $\dfrac{x^2 - 9}{x + 3}$
- [ ] **5.** Simplifique: $\dfrac{x^2 + 5x + 6}{x + 2}$
- [ ] **6.** $\dfrac{2}{x} + \dfrac{3}{x}$
- [ ] **7.** $\dfrac{x}{3} \cdot \dfrac{6}{x^2}$
- [ ] **8.** $\dfrac{4}{x} \div \dfrac{2}{x^2}$

## 🟡 Médio
- [ ] **1.** Simplifique: $\dfrac{x^2 - 9}{x^2 + 3x}$
- [ ] **2.** $\dfrac{1}{x} + \dfrac{1}{x + 1}$
- [ ] **3.** $\dfrac{2}{x - 1} - \dfrac{1}{x + 1}$
- [ ] **4.** Simplifique: $\dfrac{x^2 - 4}{x^2 + 4x + 4}$
- [ ] **5.** $\dfrac{x^2 - 1}{x + 3} \cdot \dfrac{2x + 6}{x - 1}$
- [ ] **6.** 🔀 $\left(\dfrac{x}{2} - \dfrac{1}{3}\right) \div \dfrac{x}{6}$
- [ ] **7.** 🔀 Simplifique: $\dfrac{0{,}5x + 1}{x + 2}$
- [ ] **8.** Simplifique: $\dfrac{x^2 - 3x}{9 - x^2}$

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** Simplifique: $\dfrac{1 - \frac{1}{x}}{1 - \frac{1}{x^2}}$
- [ ] **2.** Encontre as constantes $A$ e $B$ tais que $\dfrac{1}{x^2 - 1} = \dfrac{A}{x - 1} + \dfrac{B}{x + 1}$ para todo $x \neq \pm 1$.
- [ ] **3.** Se $\frac{a}{b} = 3$, quanto vale $\dfrac{a^2 + b^2}{ab}$?
- [ ] **4.** Calcule $\left(1 + \frac{1}{2}\right)\left(1 + \frac{1}{4}\right)\left(1 + \frac{1}{16}\right)\left(1 + \frac{1}{256}\right)$. (Dica: multiplique e divida por $\left(1 - \frac{1}{2}\right)$ e use a diferença de quadrados várias vezes.)

## 💻 Extra em C# (opcional)
- [ ] **1.** Compare `(x * x - 9) / (x + 3)` com `x - 3` para $x$ de $-5$ a $5$ (passo 0,5). Em que valor os resultados diferem? Por quê?
- [ ] **2.** Escreva `double Sigmoide(double x) => 1 / (1 + Math.Exp(-x));` e confira numericamente, para vários $x$, que $\sigma(x)(1 - \sigma(x)) = \dfrac{e^{-x}}{(1 + e^{-x})^2}$.
