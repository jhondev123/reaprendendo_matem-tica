## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** Fatore $a^4 + 4$. (Dica: some e subtraia $4a^2$ para formar $(a^2 + 2)^2 - (2a)^2$.) Use o resultado para mostrar que $n^4 + 4$ não é primo para nenhum inteiro $n > 1$.
- [ ] **2.** Calcule $\dfrac{2026^3 - 2026}{2025 \cdot 2027}$ sem calculadora.
- [ ] **3.** Encontre todos os pares de inteiros positivos $(x, y)$ tais que $x^2 - y^2 = 15$.
- [ ] **4.** Mostre que $n^3 - n$ é divisível por 6 para qualquer inteiro $n$.

## 💻 Extra em C# (opcional)
- [ ] **1.** Escreva `(int m, int n)? SomaEProduto(int s, int p)`, que procura inteiros com $m + n = s$ e $m \cdot n = p$ (teste os divisores de $p$, inclusive os negativos). Use-o para fatorar $x^2 + 7x + 12$ e $x^2 - x - 12$.
- [ ] **2.** Para que valores de $s$ e $p$ a função devolve `null`? O que isso diz sobre o trinômio?
