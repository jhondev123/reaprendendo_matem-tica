# Inequações do 1º Grau: Exercícios

**Teoria:** [[Inequações do 1º Grau]] · **Gabarito:** [[Inequações do 1º Grau - Gabarito]]

> [!info] Como fazer
> Dê a resposta **como intervalo** e desenhe na reta. Antes de dividir, pergunte-se: **esse número é negativo?** Corrija ao fim de cada bloco e marque o checkbox das que acertou. Errou? Registre no [[Caderno de Erros]] e refaça amanhã.

## 🟢 Fácil
- [ ] **1.** $x + 3 > 7$
- [ ] **2.** $2x \leq 10$
- [ ] **3.** $-3x > 12$
- [ ] **4.** $5 - x \geq 2$
- [ ] **5.** $3x - 2 < x + 6$
- [ ] **6.** Escreva como intervalo: (a) $x > 2$ (b) $-1 \leq x < 3$ (c) $x \leq 0$
- [ ] **7.** Quais números **inteiros** satisfazem $-2 < x \leq 3$?
- [ ] **8.** Verdadeiro ou falso: "se $a < b$, então $-a < -b$". Dê um exemplo.

## 🟡 Médio
- [ ] **1.** $\dfrac{x}{2} - 1 > \dfrac{x}{3}$
- [ ] **2.** $\dfrac{x - 1}{4} - \dfrac{2x + 1}{3} \leq 1$
- [ ] **3.** $-1 < 2x + 3 \leq 7$
- [ ] **4.** Resolva o sistema: $\begin{cases} 2x - 1 > 3 \\ x + 4 \leq 10 \end{cases}$
- [ ] **5.** 🔀 $0{,}2x - 1{,}5 \geq 0{,}5x + 0{,}3$
- [ ] **6.** 🔀 $0{,}\overline{3}\,x - \dfrac{1}{2} < \sqrt{4}$
- [ ] **7.** 🔀 $(1 - \sqrt{2})\,x > 1 - \sqrt{2}$
- [ ] **8.** Plano A: R\$ 50 fixos + R\$ 0,10 por minuto. Plano B: R\$ 30 fixos + R\$ 0,20 por minuto. A partir de quantos minutos o plano A fica mais barato?
- [ ] **9.** Um perceptron classifica uma entrada $x$ como positiva quando $2x - 3 \geq 0$. Para que valores de $x$ a classificação é positiva?

## 🔴 Difícil (estilo OBMEP)
- [ ] **1.** Quantos números inteiros $n$ satisfazem $\dfrac{1}{3} < \dfrac{n}{12} < \dfrac{3}{4}$?
- [ ] **2.** Para que valores de $k$ a solução da equação $2x - k = 5$ é maior que 3?
- [ ] **3.** Para passar, a média de 4 provas precisa ser pelo menos 7. Ana tirou 6,5, 8 e 5,5 nas três primeiras. Qual é a nota mínima que ela precisa na quarta?
- [ ] **4.** Quantos números inteiros satisfazem, ao mesmo tempo, $3x - 7 < 2x + 1 < 4x + 9$?

## 💻 Extra em C# (opcional)
- [ ] **1.** Escreva `bool Perceptron(double x, double w, double b) => w * x + b >= 0;` e encontre, testando, o menor $x$ (com passo 0,1) classificado como positivo para $w = 2$ e $b = -3$. Bate com o 🟡 9?
- [ ] **2.** Implemente `double Limitar(double v, double min, double max)` sem usar `Math.Clamp`.
