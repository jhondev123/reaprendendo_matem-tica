# Treino Misto: Lista 4 · Descubra o número (ponte para a álgebra)

**Voltar:** [[Treino Misto de Aritmética]] · **Gabarito:** [[Treino Misto - Lista 4 - Gabarito]]

> [!info] Sem calculadora · Meta: 35 minutos
> Cada problema esconde um número. Para achá-lo, **desfaça as operações de trás para a frente**: o que foi somado, subtraia; o que foi multiplicado, divida; o que foi elevado ao quadrado, tire a raiz. Isso é exatamente o que você vai formalizar em [[Equações do 1º Grau]].

- [ ] **1.** Um número multiplicado por $\frac{3}{4}$ dá $0{,}\overline{6}$. Que número é esse?
- [ ] **2.** Somando 2,5 a um número, obtém-se $-\frac{1}{4}$. Qual é o número?
- [ ] **3.** A metade de um número, menos $0{,}\overline{3}$, é igual a 1. Qual é o número?
- [ ] **4.** O quadrado de um número positivo é 2,25. Qual é o número?
- [ ] **5.** A raiz quadrada de um número é $0{,}\overline{6}$. Qual é o número?
- [ ] **6.** O cubo de um número é $-0{,}008$. Qual é o número?
- [ ] **7.** Dividindo um número por $-0{,}25$, obtém-se 1,2. Qual é o número?
- [ ] **8.** O dobro de um número, mais $\frac{3}{5}$, é igual a 0,2. Qual é o número?
- [ ] **9.** $\frac{2}{3}$ de um número mais $\frac{1}{6}$ desse mesmo número dão 15. Qual é o número?
- [ ] **10.** O inverso de um número, somado a 0,5, dá $1{,}\overline{3}$. Qual é o número?
- [ ] **11.** Pensei num número, multipliquei por 5, somei 0,5, dividi o resultado por 3 e obtive $-1{,}5$. Em que número pensei?
- [ ] **12.** Um número positivo somado ao seu quadrado dá 0,75. Que número é esse? (Teste valores simples.)
- [ ] **13.** Qual expoente $x$ faz $2^x = 0{,}125$?
- [ ] **14.** Qual número $x$ satisfaz $\sqrt{x} = 0{,}3$?
